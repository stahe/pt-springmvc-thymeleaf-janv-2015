# Introdução ao Spring MVC e ao Thymeleaf

👉 **Aceda ao curso online**:  
https://stahe.github.io/pt-springmvc-thymeleaf-janv-2015/

## Resumo

O objetivo deste documento é apresentar, através de exemplos, os conceitos fundamentais do **Spring MVC**, um framework web Java baseado no padrão **MVC (Modelo-Vista-Controlador)**.

O Spring MVC faz parte do ecossistema **Spring Framework** e fornece um framework estruturado para desenvolver aplicações web em Java robustas e fáceis de manter.

O curso também apresenta o **Thymeleaf**, um motor de vistas moderno e potente que se integra especialmente bem com o Spring MVC.

## Destinatários

Este curso destina-se a leitores com um **bom domínio da linguagem Java**.

**Não são necessários conhecimentos prévios de programação web**, uma vez que os conceitos são introduzidos de forma gradual.

## Âmbito do documento

Embora seja relativamente detalhado, este documento não pretende ser exaustivo.
O Spring é uma estrutura muito abrangente, composta por inúmeros componentes e extensões.

O documento foi concebido para **ser lido sem necessidade de um computador**, o que explica a presença de inúmeras **capturas de ecrã**.
